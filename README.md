# ExtraUITheme

ExtraUITheme lets you customize the look of the Cities: Skylines II UI directly from an in-game panel, by editing the game's CSS custom properties (colors, spacing, radii, and more) instead of hand-editing files.

[![Crowdin](https://badges.crowdin.net/extrauitheme/localized.svg)](https://crowdin.com/project/extrauitheme)

Requires [ExtraLib](https://github.com/AlphaGaming7780/ExtraLib) as a dependency.

# Features

* **Simple mode** — curated, grouped variables (panel colors, text colors, accents, borders, ...) for quick theming without digging through the full list.
* **Advanced mode** — every `:root`-overridable variable exposed as a flat, searchable, virtualized list.
* **Built-in presets** — ready-made themes you can apply instantly.
* **Custom themes** — fork, rename, and save your own themes, stored per-save under your mod data folder.
* **Import / Export** — share themes as plain JSON.
